# Zoe

一个包含多个Web项目的演示仓库。

## 项目结构

```
Zoe/
├── opencv/          # OpenCV 计算机视觉项目
├── pdf/             # PDF 相关功能项目
├── index.html       # 项目导航首页
└── README.md
```

## 项目列表

### 📄 PDF 项目
- **路径**: `pdf/demo/index.html`
- **描述**: PDF 阅读器与处理功能演示

### 🔍 OpenCV 项目
- **路径**: `opencv/index.html`
- **描述**: 计算机视觉与图像处理演示

## 使用方法

1. 克隆仓库到本地
2. 使用浏览器打开 `index.html` 查看项目导航
3. 点击对应项目卡片进入演示页面

## 技术栈

- HTML5 / CSS3 / JavaScript
- OpenCV.js
- PDF.js

## 开发

各项目独立维护，可分别进入对应目录进行开发。
